## About Me

I am a Software Engineering undergraduate majoring in Cybersecurity at Daffodil International University, with a strong interest in penetration testing, cybersecurity research, and artificial intelligence security.

My primary focus is understanding security vulnerabilities, assessing application and network security, developing security automation tools, and researching emerging threats targeting AI-powered systems.

I am particularly interested in the intersection of traditional cybersecurity and Artificial Intelligence, especially Large Language Model (LLM) security, prompt injection detection, and defensive security mechanisms.

**Academic Background**
- Degree: B.Sc. in Software Engineering
- Major: Cybersecurity
- Institution: Daffodil International University (DIU)
- Expected Graduation: April 2027

**Professional Focus**
- Penetration Testing & Vulnerability Assessment
- Web Application Security
- Network Reconnaissance & Security Testing
- AI & Large Language Model Security
- Prompt Injection Detection & Defense
- Python-based Security Automation

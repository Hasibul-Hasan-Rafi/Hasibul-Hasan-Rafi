### Hello, I'm Md. Hasibul Hasan Rafi 👋

I am a Software Engineering undergraduate majoring in Cybersecurity at **Daffodil International University, Bangladesh**.

My primary interests include **Penetration Testing, Bug Hunting, Vulnerability Assessment, Web Application Security, Network Security, and AI Security Research**.

I am passionate about identifying security weaknesses, analyzing attack surfaces, understanding adversarial techniques, and developing practical security solutions.

I am also exploring the intersection of Artificial Intelligence and Cybersecurity, with a particular research focus on **Prompt Injection Detection, Defense, and Deep Security Analysis in Large Language Models (LLMs)**.

### 🔬 Current Research

**AI-Powered Prompt Injection Detection, Defense, and Deep Analysis in Large Language Models**

My research interests include:

- Direct and Indirect Prompt Injection
- Jailbreak and Adversarial Prompt Analysis
- Prompt Injection Detection Techniques
- Attack Classification and Risk Assessment
- LLM Security Evaluation and Benchmarking
- Defensive Mechanisms and Security Architecture
- AI-driven Security Analysis

### 🛡️ Current Project

**PromptGuard AI**

An independent research and development project focused on building an AI-powered system to detect, classify, assess, and defend against prompt injection attacks targeting LLM-based applications.

### AI-Powered Prompt Injection Detection & Defense System for LLMs

<img src="https://img.shields.io/badge/STATUS-IN%20DEVELOPMENT-2563EB?style=for-the-badge"/>

**Project Overview**

PromptGuard AI is an independent research and development project focused on detecting, classifying, assessing, and defending against prompt injection attacks targeting Large Language Models and LLM-powered applications.

**Core Research & Development Modules**

| Module | Objective |
|:---|:---|
| Detection | Identify malicious prompt injection attempts |
| Classification | Categorize different attack types |
| Risk Assessment | Evaluate potential security risks |
| Defense | Explore defensive prompt security mechanisms |
| Logging | Record and analyze security events |
| REST API | Provide programmatic security functionality |
| Dashboard | Visualize security findings |
| Evaluation | Benchmark detection and defense performance |

**Planned Technology Stack**

`Python` `Machine Learning` `Hugging Face Transformers` `FastAPI` `React` `PostgreSQL`

<sub>Repository and public implementation will be linked after the project is ready for release.</sub>

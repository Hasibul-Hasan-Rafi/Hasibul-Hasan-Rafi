<img src="https://img.shields.io/badge/PROJECT-IN%20DEVELOPMENT-2563EB?style=for-the-badge"/>

An ongoing independent research and development project focused on detecting, classifying, assessing, and defending against prompt injection attacks targeting Large Language Models.

**Research and development objectives:**

- Prompt Injection Detection
- Attack Type Classification
- Risk Assessment
- Prompt Defense Mechanisms
- Security Logging and Analysis
- REST API Development
- Security Dashboard
- Benchmark-based Evaluation

**Planned Technology Stack:**

`Python` `Machine Learning` `Hugging Face Transformers` `FastAPI` `React` `PostgreSQL`
